# NEST CBT - Administrator Portal

## Project Purpose

This is the Administrator Portal of the National AI Examination Platform.

This application is used by:

- Examination Administrators
- Super Administrators
- Examination Authorities

This application is NOT an examination interface.

The primary objective is to provide enterprise-grade examination management.
